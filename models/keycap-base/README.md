# 키캡 밑판 · 스위치 결합부 길이 조절

`keycap-base-original.stl`은 받은 키캡 밑판(18×18×9.2mm, 윗면 14.3mm 홈 깊이 약 2.9mm, 윗판을 밀어 빼는 구멍 2개)입니다. 아래의 십자 결합부(5.5mm 사각 기둥, 십자 4.16×1.24mm)는 원래 스커트 바닥(Z=0)까지 내려오고 십자 구멍 깊이가 약 4.2mm입니다.

| 파일 | 결합부 아래쪽을 줄인 길이 | 십자 구멍 깊이 | 키캡 위치 |
| --- | --- | --- | --- |
| `keycap-base-socket-0.5.stl` | 0.5mm | 약 3.7mm | 0.5mm 낮게 · MX 십자(약 3.6mm)를 거의 다 물어요 **(추천)** |
| `keycap-base-socket-1.0.stl` | 1.0mm | 약 3.2mm | 약 0.6mm 낮게 · 십자 끝이 구멍 천장에 닿아 멈춤 |
| `keycap-base-socket-1.5.stl` | 1.5mm | 약 2.7mm | 약 0.6mm 낮게 · 무는 길이가 짧아 덜 단단 |

원본처럼 입구에 0.2mm 깔때기(0.4mm 높이)를 다시 만들었습니다. 결합부가 스커트 바닥보다 위에서 끝나므로 **스커트 바닥을 베드에 두고 출력하면 결합부 아래에 서포트**가 필요해요(슬라이서의 자동 서포트 · "빌드 플레이트에서만"으로 충분).

`python3 models/keycap-base/shorten_socket.py 0.8` 처럼 원하는 길이로 다시 만들 수 있어요.

## 도장으로 쓰려면

부스의 **입체 방향 → 🔖 도장**을 고르면 윗판이 바닥 3.0mm + 글자 1.5mm(전체 4.5mm)로 바뀌고 글자가 좌우 반전됩니다. 윗판을 밑판 홈(약 2.9mm)에 끼우면 글자가 테두리보다 약 1.5mm 위로 올라와, 인주를 찍을 때 테두리는 묻지 않고 글자만 찍혀요. 기본(볼록·오목) 윗판은 1.5mm + 글자 0.6~1mm라 테두리보다 낮습니다.

## 바깥을 줄인 둥근 키캡 (보관함·다른 끼움 자리가 빡빡할 때)

윗면의 **판 끼우는 홈 14.3mm는 그대로**라 부스에서 뽑은 14×14mm 판이 똑같이 끼워져요. 바깥만 줄이고, 원본과 한눈에 구분되게 **더 둥글게** 만들었어요: 모서리를 아래부터 둥글리고(R2.8→3.4, 원본은 2.0→4.2), 윗면 바깥 테두리를 둥글게 굴리고(R0.45), 바닥 모서리는 0.4mm 45°로 깎았어요(첫 층이 퍼져도 치수 안).

![단면 비교](preview-outer.png)

| 십자 기둥(소켓) | 바닥 17mm | 바닥 16.5mm |
| --- | --- | --- |
| 0.5mm 줄임 **(추천)** | `keycap-base-socket-0.5-outer17.stl` | `keycap-base-socket-0.5-outer16.5.stl` |
| 1.0mm 줄임 | `keycap-base-socket-1.0-outer17.stl` | `keycap-base-socket-1.0-outer16.5.stl` |
| 1.5mm 줄임 | `keycap-base-socket-1.5-outer17.stl` | `keycap-base-socket-1.5-outer16.5.stl` |

| | 원본 | 17mm | 16.5mm |
| --- | --- | --- | --- |
| 바깥 (바닥 → 맨 위) | 18.0 → 16.9mm | 17.0 → 16.0mm | 16.5 → 16.0mm |
| 치마 벽 (가장 얇은 곳) | 1.2mm | 0.6mm (옆면 0.7) | 0.6mm |
| 홈 둘레 벽 | 1.3mm | 0.86mm 이상, 둥근 윗 테두리 끝으로 갈수록 얇아짐 | 같음 |

- 십자 기둥·판 홈·돌기·판 빼는 구멍은 각 소켓 버전 그대로예요. 이미 쓰던 소켓 길이와 같은 줄에서 고르면 돼요.
- 치마 벽이 0.6mm보다 얇아지지 않게 치마 안쪽 아래의 벌어진 부분과 모서리를 조금 메웠어요(16.5mm에서 스위치 들어가는 공간이 한쪽 최대 약 0.15mm 좁아짐). **먼저 17mm로 맞춰 보고**, 그래도 빡빡하면 16.5mm를 쓰세요.
- `python3 models/keycap-base/slim_outer.py 16.8`처럼 원하는 바닥 크기로 다시 만들 수 있어요(세 소켓 버전 모두).

## 낮은 키캡 · 십자 기둥 2mm 줄임 (2026-10-26)

윗면 테두리를 **1mm 낮춰**(높이 9.2 → 8.2mm, 판 홈 깊이 2.9 → 1.9mm) 부스에서 뽑은 판의 바닥(1.5mm)과 거의 같은 높이가 되게 했어요. 계산상 테두리가 판 바닥 윗면보다 0.5mm 높아요(원본은 1.5mm). 홈 벽의 곧은 구간(바닥에서 0.8~1.8mm 높이)에서 1mm를 빼고 그 위를 내렸기 때문에, 판을 잡는 돌기 끝 모양과 입구 경사·둥근 테두리는 그대로예요(돌기의 곧은 부분만 1mm 짧아짐). 십자 기둥은 **1.5mm 줄인 것(추천)**과 **2mm 줄인 것**이 있어요(2mm는 `python3 shorten_socket.py 2.0`). 2mm는 십자 구멍 깊이가 약 2.2mm라 스위치를 무는 길이가 짧아요.
