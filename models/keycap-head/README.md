# 큰 도장 머리 (23mm 키캡 + 20mm 이름판)

키캡 밑판(18mm, 윗판 14mm) 대신 **본체 윗면과 같은 23×23mm** 머리를 씌워, 윗면 도장 글자를 **20×20mm 판**에 크게 새깁니다(14mm 판보다 면적 약 2배).

![조립과 단면](preview.png)

| 파일 | 내용 |
| --- | --- |
| `stamp-head-23.stl` | 머리(키캡). 파일 그대로 **치마·십자 기둥이 베드 쪽**으로 출력(서포트 없음). 스위치와 만나는 십자 입구가 베드 면이라 매끈하고, 서포트 없이 뜨는 면(속 천장, 아래 턱)은 모두 스위치 쪽이라 안 보여요 |
| `stamp-plate-20-sangsang.stl`, `-aiera.stl` | 시험용 이름판 20×20 · 바닥 3.0 + 글자 1.5(좌우 반전 = 찍으면 바르게) |
| `stamp_head.py` | 위 파일을 만드는 스크립트(치수는 맨 위 상수) |

## 구조 (mm)

- 머리 바깥 23×23(모서리 R3.35, 본체 윗면과 같음) · 높이 8.5 · 윗면 홈 20.3×20.3 깊이 2.9 · 판 빼는 구멍 Ø2.2 두 개
- 아래 치마 19×19 → 본체의 19.6mm 우물에 들어가므로 **이미 뽑은 본체 그대로** 씁니다
- 십자 결합부는 기존 밑판과 같은 규격: **둥근 Ø5.5mm 기둥**, 십자 4.16×1.24, 깊이 4.2, 입구 깔때기. (첫 버전은 5.5mm 사각 기둥이라 모서리가 스위치 윗몸에 걸려 눌리지 않았어요)
- 아랫면은 치마에서 1mm 턱(본체 윗면에 닿는 면) 뒤 45° 경사로 바깥까지 이어져 서포트가 필요 없어요. 치마와 기둥 바닥 모서리는 0.3mm 깎아 첫 층 퍼짐을 막아요
- 가만히 있을 때 머리 아랫면이 본체 윗면에서 **3.8mm** 떠 있고, 누르면 스위치가 끝까지(4mm) 내려가기 직전에 **본체에 닿아 멈춰요**. 도장 찍는 힘이 스위치가 아니라 본체로 갑니다.

## 부스 연결

부스 첫 화면의 **무엇을 새길까?** 옆에서 **🔖 큰 도장 20mm**를 고르면 20×20mm 도장 판(바닥 3.0 + 좌우 반전 글자 1.5, 모서리 R4)을 만들어 그대로 출력합니다. 이 머리의 홈(20.3mm)에 맞아요. **🔑 키캡 14mm**는 기존 키캡 밑판용 판입니다.
