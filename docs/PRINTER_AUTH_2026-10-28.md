# 풍풍 미니 02 연결 확인 — 2026-10-28

## 최신 결과

사용자가 **“갑자기 연결이 됐어”**라고 크롬북 연결 성공을 확인했다. 현재 상태를 계속 연결 실패로 기록하지 않는다. 회복 원인은 미확정이다. 재시작·코드 변경 여부도 확인되지 않았으므로 특정 조치로 해결됐다고 단정하지 않는다. **이번 회차에서 실제 출력 완료는 아직 확인하지 않았다.**

## 실패 당시 증거

- 대상: 풍풍 미니 02, SN 끝 2550, 당시 IP 192.168.0.2.
- 크롬북 검색은 성공, 코드 입력 뒤 인증 거절. 사용자는 본체 코드가 소문자이며 LAN Only·개발자 모드가 켜져 있다고 확인했다.
- PC Wi-Fi 연결 후 같은 LAN에서 대상과 LAN Only 광고를 확인했다.
- PC 기본 TLS MQTT와 앱 DirectTLS MQTT 모두 CONNACK 5, 기본 FTPS도 530으로 거절됐다. 크롬북 UI만의 문제로 설명할 수 없다.
- 실제 코드는 문서·Git·로그에 남기지 않았다. 시험용 임시 파일 삭제. 시험은 인증만 수행했고 출력·예열·이동·파일 업로드 명령을 보내지 않았다.

## 변경·검증

소문자도 유효하므로 자동 대문자 변환이나 소문자 경고를 넣지 않는다. 문구를 **프린터는 응답했지만 로그인을 거절했어요**로 구분하고 본체의 현재 코드·두 모드 확인 및 잠시 후 재연결을 안내한다. 코드 오타만 원인이라고 단정하지 않는다.

가짜 테스트 코드의 대소문자를 바꿔 실패/성공을 검증하는 회귀 검사를 추가했다. 전체 검사 170개 통과, 마지막 안내 변경 뒤 관련 검사 17개 재통과. 온라인 화면에 반영하며 IWA/APK 서명 버전은 이번에 변경하지 않았다.

진단 결과는 비공개 로컬 artifacts/domain-20261028/mini-02-auth-result.json 및 mini-02-ftps-auth-result.json에 보관했다.
