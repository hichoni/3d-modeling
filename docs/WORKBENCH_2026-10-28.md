# 1단계 작업대 개선 · 2026-10-28

이번 범위는 부스 체험의 도구 패널, 편집 기록, 현재 작품 비교 그림이다. 진입 주소는 [내 맘대로 만들기](https://hichoni.github.io/3d-modeling/index.html?start)다. 루트는 대문으로 이동한다. 일반 STL 스튜디오·프린터 프로토콜·받침 규격은 변경하지 않았다.

## 화면과 동작

| 영역 | 동작 |
| --- | --- |
| 작업대 상단 | 이름, 이름/이니셜/그림, 14mm 키캡/20mm 큰 도장, 선택 요약, 취소·다시 버튼 |
| 글씨·그림 | 실제 입력 글자의 글씨체 4종 비교 또는 그림·캐릭터 선택 |
| 입체 느낌 | 지금 작품의 볼록·말랑·오목·뚫림·도장 비교, 새김 높이 |
| 꾸미기 | 테두리, 작은 포인트, 미리보기 색. 그림은 글씨·그림 탭에 모음 |
| 키링 칸 | 실제 내용 썸네일, 위치, 편집 중/완성/빈칸. 완성은 보관된 디자인 상태 |

탭은 키보드 좌우 방향키, Home/End로 이동한다. 데스크톱에서는 입력과 탭을 고정하고 `#toolBody`만 스크롤하며, 모바일에서는 내부 스크롤 없이 페이지 전체를 스크롤한다. 칸 선택 카드가 커져도 3D 모델을 덮지 않도록 하단 조작 영역 높이를 관찰해 모델 공간에 반영한다.

## 편집 기록

- `src/design-history.js`: 편집 가능한 값만 저장하는 작은 독립 기록 클래스. 메쉬·프린터·작업 토큰은 저장하지 않는다. 칸마다 이전 기록 최대 50개, 메모리에만 존재한다.
- `src/design-workbench.js`: 현재 `pairSlot`의 기록 선택, 취소/다시 실행, 탭·썸네일 UI. 텍스트/높이의 800ms 이내 연속 입력을 같은 기록으로 묶고 포커스를 떠나거나 슬라이더 조작을 마치면 묶음을 끝낸다.
- `src/app.js`: UI 변경 후 기록을 남기고, 복구는 `change(true,{history:false})`로 실제 모델을 다시 만든다. 이때 오래된 슬라이스·세션 작업 참조를 무효화한다. 대기 중인 칸 전환은 취소하며 기존 revision 검사로 오래된 폰트/모델 응답을 버린다.
- 다른 칸으로 가도 그 칸의 기록을 보존한다. 시점 변경·도구 탭 이동·끼워보기·칸 이동 자체는 취소 대상이 아니다. 칸 수를 줄여 활성 작품 위치가 바뀌면 기록도 같이 옮긴다.
- 입력칸 밖의 Ctrl/⌘ Z, Ctrl/⌘ Shift Z, Ctrl Y는 작품 기록을 조작한다. 입력칸 안에서는 브라우저의 기본 텍스트 편집 단축키를 유지한다. 출력 중·한글 조합 중에는 작품 기록을 적용하지 않는다. 출력/전송 취소 기능과 별개다.
- 새 페이지 방문에는 이전 편집 기록이 복원되지 않는다. 기존 단일 작품 localStorage 복원 기능은 유지한다. ‘새로 시작하기’는 새 체험이므로 이전 칸과 기록을 비운다.

## 썸네일

현재 `S`의 복사본으로 `letterLayer`/글리프/그림 그리기를 재사용한다. 새 3D 메쉬를 만들지 않고 낮은 해상도 Canvas에서 음영을 붙인다. 캐릭터의 볼록/말랑은 몸과 세부 모양의 두 단계를 표현한다. 도장은 좌우를 뒤집는다. 뚫림의 연결 다리나 말랑 표면을 정확하게 생성하는 대체 슬라이서가 아니다. 화면에도 비교용임을 표시했다.

- 120ms 동안 연속 요청을 합치고 현재 탭·표시 중인 칸만 갱신한다.
- 글꼴 준비 뒤 요청 번호가 최신인지 확인하고 그린다. Canvas별 디자인 키가 같으면 다시 그리지 않는다.
- 기존 엔진이 전역 상태를 참조하므로 `withPreviewDesign`에서 **동기적으로만** 값을 잠깐 바꾼 뒤 `finally`에서 `S`, `characterPart`, `lastCellMinMm`를 복구한다. 이 안에 `await`를 추가하면 안 된다.
- 썸네일 오류가 실제 모델 편집 상태를 오염시키지 않는 회귀 검사를 포함했다.

## 검증·배포·남은 범위

`node scripts/build.cjs`로 공개 파일과 ZIP을 생성하고, `node --test tests/*.test.cjs`로 모의 프린터 기반 전체 153개를 통과했다. 실제 프린터는 건드리지 않았다. 브라우저에서 빠른 취소/복원, 여러 칸, 한글 이름·픽셀·그림·색, 단축키, 새 작품 초기화, 반응형 크기, 실제 11층 슬라이싱을 확인했다.

배포 완료 여부·Actions 링크·확인 커밋은 [인수인계 최신 절](HANDOFF.md)에 기록한다. 실제 저사양 크롬북/태블릿의 터치·한국어 IME·장시간 편집 성능 검사는 별도로 남는다. 슬라이싱/출력 확인 카드 리디자인, 전체 세트의 로컬 저장, 일반 STL 스튜디오 리디자인은 이번 범위 밖이다.
