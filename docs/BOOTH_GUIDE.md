# 부스 운영 안내

## 5분 체험 진행

| 시간 | 참가자 행동 | 운영자 멘트 |
| --- | --- | --- |
| 0~2분 | 이름·이니셜·그림 선택 | “작은 네모에 나를 담아볼까요?” |
| 2~3분 | 글꼴·볼록/오목·높이 선택 | “높이를 바꾸면 평면이 입체가 돼요.” |
| 3~4분 | 층 쌓기 재생·실제 슬라이싱 | “프린터는 얇은 층을 한 줄씩 그려요.” |
| 4~5분 | 대기표 수령 또는 STL 전달 | “이 번호로 내 작품을 찾아요. 출력이 끝나면 딸깍 조립해요.” |

타이머가 끝나도 작업은 사라지지 않습니다. 출력 시간은 5분에 포함되지 않습니다.

## 크롬북 참가자

출력 PC에서 `configure-booth.cmd`로 사용할 미니 여러 대를 등록하고 ⚙ 화면의 **부스 링크**를 공유하세요. 각 크롬북에서 ‘미니 매칭’을 열어 현장의 본체 번호와 같은 미니를 선택합니다. 이후에는 이 브라우저가 매칭을 기억합니다. 참가자에게 CMD를 실행하거나 프로그램을 설치하라고 안내할 필요가 없습니다. 각 크롬북에서 바로 출력 버튼으로 해당 미니를 시작합니다. 중앙 PC의 PIN은 전체 관리와 문제 해결에 사용합니다. 상세 조건은 [크롬북 안내](CHROMEBOOK.md)에 있습니다.

## 시작 전

- 로컬 공방은 `start-workshop.cmd`로 실행합니다. 화면만 체험하면 GitHub Pages도 사용할 수 있습니다.
- 현장 중계기, A1 mini 0.4mm 노즐, 외부 PLA 스풀, 텍스처 PEI 베드, SD 카드를 준비합니다.
- 운영자 PIN은 참가자에게 알려주지 않습니다. 운영자 창을 닫으면 화면 잠금이 다시 걸립니다.
- 프린터가 없어도 디자인과 슬라이싱은 할 수 있습니다. 연결되지 않은 상태를 출력 중이라고 표시하지 않습니다.

## 작품 하나 출력하기

1. 참가자가 이름/그림을 완성합니다. 외곽 14×14mm, 바닥 1.5mm는 고정입니다.
2. 두 번째 단계에서 브라우저가 자동 슬라이싱합니다. 층별 실제 경로와 작품 경로 예상 시간·재료량을 확인합니다.
3. 출력 화면에서 사용할 미니를 고릅니다. 한 대면 별도 매칭 대화상자가 필요 없습니다.
4. 베드의 이전 출력물을 치우고 텍스처 PEI·0.4mm 노즐·외부 PLA를 준비한 뒤 **바로 출력**을 누릅니다. 실제 시작 버튼이며 대기표나 개별 PIN 승인은 없습니다.
5. 출력 화면에서 베드 레벨링·자동 유량 보정을 선택하고(기본 모두 켬) 파일을 한 번 보냅니다. 3D 설명 모형, 실제 온도·목표 온도와 진행 상태를 함께 보여줍니다. 첫 층은 현장에서 살펴봅니다.
6. 완료 후 충분히 식혀 꺼내고 받침·스위치에 결합합니다. 다음 작품을 자동으로 출력하지 않습니다.

상단 숫자는 체험 시작 1회당 1명, 완료된 출력 1개 기준입니다. 새로고침·디자인 수정·전송 재시도는 중복 집계하지 않습니다. ‘새 작품 만들기’로 다음 체험을 시작합니다. 같은 공방 연결에서는 전체 합계, 미연결에서는 이 기기 합계를 표시합니다.

‘전송 결과 확인 필요’ 상태에서는 시작을 반복하지 마세요. 본체를 확인하고, 프린터가 대기 상태이며 베드가 비었다면 운영자 화면의 ‘이전 작업 닫기’로 정리합니다. 프린터 상태와 작업이 일치할 때만 웹 중지가 가능합니다. 그 외에는 본체에서 중지하세요.

## 온라인 사이트에서 가져온 파일

STL을 Bambu Studio에 mm 단위, 100% 크기로 불러옵니다. 평평한 바닥이 베드 방향입니다. A1 mini / 0.4mm / 0.20mm Standard / Generic PLA / Textured PEI 프리셋을 선택하고 경로를 확인합니다. ‘작품 묶음’에는 STL, 다시 편집 가능한 `작품.json`, 제작 안내가 들어 있습니다.

STL에는 색상이 없습니다. 화면의 색은 참가자가 상상하는 색이고, 실제 출력 색은 장착한 필라멘트입니다. 받침은 별도 준비물이므로 이 앱에서 함께 출력하지 않습니다.

## 종료

대기 목록의 미출력 작품을 확인하고 참가자 수령 상황을 정리합니다. 서버를 종료해도 프린터는 계속 움직일 수 있으므로 본체 상태를 확인합니다. 이름·작품은 이 PC에 저장됩니다. 필요한 파일을 비공개로 백업하고 행사 후 보관 방침에 맞게 정리하세요.
