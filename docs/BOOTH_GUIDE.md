# 부스 운영 가이드

## 준비

1. `index.html`을 체험 PC에 다운로드하고 Chrome/Edge에서 엽니다. 단일 파일에 글꼴과 3D 엔진이 모두 들어 있습니다.
2. 화면의 전체 화면 버튼 또는 브라우저 전체 화면 기능을 사용합니다. 너무 좁은 화면에서는 스크롤이 필요합니다.
3. 다운로드 폴더 위치를 정하고 운영자에게 알려줍니다. 참가자별 ZIP 파일이 실제로 내려받아지는지 확인합니다.
4. 사용할 프린터와 슬라이서로 판형, 긴 이름, 음각, 손잡이 모델을 각각 미리 출력해 봅니다.
5. 샘플 결과를 기준으로 허용 크기·손잡이 여부·접수 인원·수령 방법을 정합니다. 앱은 인원 수나 프린터 대기열을 관리하지 않습니다.
6. 실제 인주와 재료로 찍어봅니다. 단단한 출력물은 종이와 고르게 접촉하도록 받침이나 완충층이 필요할 수 있습니다.

## 참가자에게 안내할 말

### 0:00–1:00 / 취향 고르기

“5분 동안 내 이름을 입체 도장으로 만들어볼 거예요. 마음에 드는 스타일을 하나 골라주세요. 오른쪽 도장을 손으로 돌려볼 수도 있어요.”

### 1:00–2:30 / 나를 새기기

“이름도 좋고 별명도 좋아요. 2~4글자가 또렷하게 나와요. 글씨를 고른 뒤 ‘찍어 보기’를 눌러보세요. 도장 면에서는 글자가 거꾸로 보이지만, 찍으면 바르게 나와요.”

### 2:30–4:00 / 입체로 다듬기

“크기를 바꾸고 새김 높이를 움직여볼까요? 평평한 글자에 높이를 더하는 게 3D 모델링이에요. 판만 만들면 재료가 적게 들고, 손잡이를 더하면 잡기 편해져요.”

장비 수량과 대기열에 맞춰 손잡이 선택을 안내합니다. 5분 타이머는 안내용이며 시간이 지나도 작품을 삭제하거나 강제로 종료하지 않습니다.

### 4:00–5:00 / 완성 & 접수

“완성 버튼을 누르고 출력용 묶음을 저장해주세요. 제작 번호를 확인하면 운영자가 출력과 수령 방법을 안내해드릴게요. 화면의 색은 미리보기 색이고, 실제로는 준비된 재료 색으로 나와요.”

브라우저가 파일을 저장했는지 다운로드 목록에서 확인합니다. 앱은 다운로드 요청만 할 수 있으며 프린터 접수 여부를 알 수 없습니다.

## 출력 접수 순서

1. 참가자와 **제작 번호**를 확인합니다. 이름만으로 접수하면 동명이인이 섞일 수 있습니다.
2. ZIP을 풀고 다음 네 파일을 확인합니다.
   - `SG-날짜-식별자_이름.stl`: 실제 3D 모델
   - `작품카드.png`: 참가자가 볼 수 있는 인영 카드
   - `제작설정.json`: 글자, 치수, 글꼴, 반전, 손잡이 등 제작 기록
   - `출력안내.txt`: 운영자 확인 순서
3. STL을 슬라이서에서 **mm** 단위로 엽니다. 바닥이 Z=0이며 **새겨진 면이 위쪽**입니다. 글자는 이미 좌우 반전되어 있으므로 다시 반전하지 않습니다.
4. 메쉬는 부품별 닫힌 껍질이 겹치는 구조입니다. 사용하는 슬라이서에서 겹친 볼륨 결합/병합을 확인하고 필요하면 메쉬 수리 기능을 사용합니다. 앱이 단일 Boolean 솔리드를 보장하지는 않습니다.
5. 레이어 미리보기로 글자의 가는 획, 테두리, 바닥과 글자의 연결, 손잡이 위 판의 돌출부를 확인합니다. 손잡이 모델은 필요에 따라 서포트를 사용합니다.
6. 프린터/소재에 맞는 프로필을 선택하고 실제 예상 시간을 확인합니다. 앱은 무게나 출력 시간을 보장하지 않습니다.
7. 제작 번호와 출력 순서·수령 시간을 별도 운영표에 기록합니다. 개인정보가 꼭 필요하지 않다면 제작 번호만 사용합니다.
8. 출력 후 번호와 인영을 대조하여 전달합니다.

## 다음 참가자

완성 화면의 **다음 참가자 시작** → **새로 시작**을 누르면 이름, 스타일, 치수, 손잡이, 색, 타이머, 제작 번호가 초기화됩니다. 브라우저 다운로드 폴더의 파일은 남습니다. 운영자는 행사 후 보관 기준에 맞게 다운로드 파일을 정리합니다.

초기화 대화상자에서 **계속 만들기**를 누르면 작업이 유지됩니다. 앱을 새로고침하면 저장되지 않은 작업은 사라집니다.

## 문제 해결

| 상황 | 조치 |
| --- | --- |
| 화면이 비거나 글꼴 로딩 안내가 남음 | HTML 전체를 다시 다운로드하고 Chrome/Edge에서 엽니다. GitHub 코드 뷰에서는 실행되지 않습니다. |
| 3D 미리보기가 나오지 않음 | WebGL을 사용할 수 있는 브라우저에서 엽니다. ‘찍어 보기’로 2D 결과를 확인할 수 있습니다. |
| 완료 버튼 비활성 | 한글/영문/숫자 1~6자인지 확인하고 모델 갱신을 기다립니다. |
| 가는 획 경고 | 글자를 줄이거나 크기를 늘리고, ‘조금 더 다듬기’에서 획 보강을 올립니다. |
| 다운로드 없음 | 브라우저 다운로드 목록/차단 상태를 확인합니다. 중복 클릭 대신 파일 유무를 먼저 확인합니다. |
| 같은 이름 파일이 여러 개 | 제작 번호로 구분합니다. 같은 작품을 다시 저장하면 같은 제작 번호가 사용됩니다. |
| 체험 시간이 5분 초과 | 작품은 유지됩니다. 마무리 안내 후 저장하세요. |
| 화면과 출력 색상이 다름 | STL에는 색이 없습니다. 준비된 필라멘트 색상을 안내합니다. |

## 운영자가 결정해야 할 부분

- 장비별 출력 프로필과 사전 샘플 품질 기준
- 손잡이 허용 여부와 최대 치수
- 한 번에 배치할 출력물 개수 및 접수 마감
- 참가자에게 전달할 시점과 장소

이 설정은 현재 앱에서 자동 제어하지 않습니다. 행사에 맞춰 `src/state.js` 기본값과 `src/index.html` 슬라이더 범위를 조절할 수 있습니다.
