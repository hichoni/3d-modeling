# Click Studio · STL 웹 스튜디오

2026-10-21 추가한 새 스튜디오 베타입니다. **[Click Studio 열기](https://hichoni.github.io/3d-modeling/studio.html)**. 기존 14mm 키캡 체험과 별도 화면으로 제공합니다. 기본 엔진은 브라우저에서 실행하며 Bambu Studio를 설치하지 않아도 STL을 준비하고 슬라이싱합니다. A1 mini 전송에는 같은 네트워크의 공방 중계기 API v8이 필요합니다.

## 기능

- 바이너리·ASCII STL 드래그 업로드, 플레이트에 최대 6개 모델. 전체 6MB·120,000 triangles 제한.
- A1 mini의 180mm 베드 표시, 출력 허용 범위 170×170×160mm. 가장자리 5mm와 종료 상승 여유를 확보합니다.
- 모델 선택·드래그 이동·중앙 정렬·행 배치·균일 배율·치수 입력·XYZ 회전·복제·삭제·실행 취소/다시 실행.
- 열린/비정상 모서리·퇴화 삼각형·범위 이탈·모델 간 겹침 진단. 자동 메쉬 수리는 제공하지 않습니다.
- 0.12/0.16/0.20mm, Generic PLA/Bambu PLA Matte, 채움 0~100%의 고정 선택, 외벽 2~5줄, 자동 일반 서포트·브림 3줄, 표준/느린 속도.
- 실제 레이어별 외벽·표면·속 채움·서포트 표시, 단일 층/누적 모델 보기, 이동 경로·재생, 경로 시간·PLA 재료량.
- 프로젝트 JSON 저장·불러오기, 배치된 STL, 경로 검토용 G-code, 중계기가 준비한 출력용 3MF 저장.
- 공유 부스 연결·기존 1:1 매칭·로컬 PC 연결 설정. 출력 준비 후 파일·프린터·옵션을 검토하고 명시적으로 시작합니다.

## 기계 파일과 제한

새 `/api/studio-jobs`만 스튜디오 규격을 받습니다. 기존 `/api/browser-jobs`의 14mm 검증은 유지합니다. 메쉬·경로·프리셋을 중계기에서 다시 검증하고 임의 가열/홈 명령은 거절합니다.

큰 모델에서는 고정 A1 mini 준비·종료 절차의 **레벨링 사각형, 모델 뒤 상승 높이, 후반 Z 이동**을 모델·경로 높이에 맞게 계산합니다. 시작의 필수 가열·홈·닦기와 보정 조건 블록은 공식 mini 절차를 유지합니다. 기존 14mm 실물 출력 기록은 이 큰 모델 조합의 실물 검증이 아닙니다.

출력은 외부 PLA·0.4mm 노즐·텍스처 PEI 전용입니다. 트리 서포트·AMS·색상별 출력·다른 노즐·다른 프린터·PETG를 지원하지 않습니다. 온도와 체적 유량은 기존 220/65°C·12mm³/s 범위입니다. 서포트가 모든 오버행의 성공을 보장하지 않으며 미리보기와 첫 층/실물을 확인해야 합니다.

시간·재료 추정은 모델 경로 범위입니다. 예열·퍼지·레벨링·유량 보정·종료 동작은 별도입니다. `.paths.gcode`는 직접 출력하는 파일이 아닙니다. 최종 3MF는 자신의 작업에 한해 중계기에서 저장하며 저장만으로 출력하지 않습니다.

프린터 IP·일련번호·액세스 코드·PIN·작업 STL은 공개 코드에 포함하지 않습니다. 사용자가 업로드한 모델은 출력 준비 전까지 브라우저에 머무릅니다. ‘프로젝트 저장’은 사용자가 명시적으로 내려받는 파일입니다.

## 실행

`node scripts/build.cjs`가 기존 index.html과 새 studio.html, 운영자 ZIP을 생성합니다. `node scripts/serve.cjs`의 http://127.0.0.1:5186/studio.html 또는 중계기의 http://127.0.0.1:5188/studio.html 에서 엽니다. 브라우저 엔진·공통 코어 수정 시 먼저 `node tools/slicer/build.cjs`를 실행합니다.

엔진은 고정 upstream을 수정하지 않고 단일 worker에서 자동 서포트의 shadow stack을 직렬 계산하도록 어댑터를 둡니다. 외부 스크립트·WASM 요청·SharedArrayBuffer가 필요하지 않습니다.

## 검증 상태

자동 검사 62개가 통과했습니다. 바이너리/ASCII·불량 메쉬, 회전/배율/배치, 실제 worker 슬라이싱, T자 오버행의 자동 서포트 생성, 160mm 높이의 종료 상승, 프로필/경로/모델 대응, 3MF 해시, 소유자 격리, 중복 시작·중지까지 포함합니다. 14mm 기존 검증도 유지합니다.

브라우저에서 STL 업로드·숫자 배율·회전·두 모델 배치·0.16mm 슬라이싱(187층), 초기 마지막 층 표시, 가상 프린터 1:1 매칭·파일 준비·출력 전 체크·모의 전송을 확인했습니다. 모의 서버는 실제 MQTT/FTPS와 격리합니다. 큰 모델·서포트의 실물 시험과 실제 학교 ChromeOS/6대 시험은 완료하지 않았습니다.

## 다음 현장 시험

1. 기존 작업을 끝낸 뒤 runtime 전체를 비공개 백업하고 최신 운영자 ZIP으로 교체합니다. 기존 설정·매칭·통계·작업 폴더는 보존합니다.
2. API v8 중계기를 실행하고 같은 공방 링크로 studio.html에 연결합니다. 각 크롬북은 사용 가능한 미니를 매칭합니다.
3. 20mm 테스트 블록을 기본 설정으로 계산하고 첫 층·종료 상승·치수·표면을 확인합니다. 다음에 브림과 T자 서포트를 따로 비교합니다. 첫 시험은 사람이 곁에서 확인합니다.
4. 실제 모델은 바닥 방향·서포트·치수와 레이어를 확인한 뒤 출력합니다. 긴 출력은 5분 부스 체험과 구분해서 운영합니다.
