# 검증 기록

검증일: 2026-10-19 (Asia/Seoul)

## 자동 테스트 — 9개 통과

명령: `node --test tests/engine.test.cjs`

1. 1~6자와 4개 배치에서 각 글자 칸이 유효하고 영역을 벗어나지 않음
2. 자동 배치와 전통 배치의 읽는 방향
3. 중첩 윤곽의 구멍과 섬 보존, 압출 부피
4. marching squares 외곽/구멍 추출
5. 5개 밑판 모양의 치수, 높이, 양의 부피
6. binary STL 길이/삼각형 수/유한 좌표/단위 법선
7. ZIP CRC-32, UTF-8 한글 파일명, 중앙 디렉터리
8. 지원 문자와 파일명 정리
9. 단일 HTML에 글꼴/라이브러리 포함, 외부 script/link/font 요청 없음

JavaScript 구문 검사와 `node scripts/build.cjs` 빌드도 통과했습니다. 최종 `index.html`은 약 12.3 MB입니다.

## 브라우저에서 확인한 흐름

로컬 HTTP 서버와 Codex 내장 Chromium 계열 브라우저에서 실제 UI를 조작했습니다.

- 첫 화면의 스타일 썸네일, 한글 글꼴, 3D 도장, 인영 미리보기 표시
- 다음 단계 이동, `김하늘` 입력, 글꼴 변경
- 원형 선택, 육각 손잡이 선택
- 슬라이더 키보드 조작으로 가로 25 mm, 새김 1.3 mm 변경
- ‘찍어 보기’ 전환과 완성 화면의 이름/제작 번호/치수 확인
- 출력용 ZIP을 실제로 다운로드한 뒤 압축 구성과 JSON 설정 확인
- ‘다음 참가자 시작’ 확인 대화상자 이후 기본 이름/모양/판형/타이머 초기화
- 빈 이름 입력 시 다음 버튼과 완료 단계 비활성화

## 실제 다운로드한 파일 검사

원형 25 × 25 mm, 육각 손잡이 12 mm, 밑판 3 mm, 새김 1.3 mm의 샘플입니다. 개인별 테스트 파일은 저장소에 포함하지 않습니다.

| 항목 | 결과 |
| --- | --- |
| ZIP 내용 | STL, 작품카드 PNG, 제작설정 JSON, 출력안내 TXT |
| STL 크기 | 129,684 bytes |
| 삼각형 | 2,592 |
| 경계 치수 | 25 × 25 × 20.05 mm |
| 최저 Z | 0 mm |
| 퇴화 삼각형 | 0 |
| 열린 경계 | 0 |
| 비정상 연결 수의 모서리 | 0 |

모서리 검사는 좌표를 0.0001 mm 단위로 양자화하고 동일 좌표의 부호 있는 0을 정규화했습니다. 이 검사는 닫힌 껍질 상태에 관한 검사이며, 겹친 메쉬의 Boolean 합집합이나 모든 슬라이서에서의 적합성을 증명하지는 않습니다.

재검사 도구: `node scripts/inspect-stl.cjs <파일.stl>`

## 아직 검증하지 않은 범위

- 실제 프린터 출력, 인주 찍기, 소재별 내구성, 사용 장비의 슬라이서 호환성
- 모든 글꼴/글자/크기 조합의 인쇄성
- 실제 태블릿 터치, 휴대폰 기기, Safari 및 Firefox
- WebGL 불가 환경의 화면 폴백, 다운로드 차단 환경, 전체 화면 권한 거부
- 5분 타이머 만료까지 장시간 기다리는 실기 검증
- 최종 데스크톱 높이 보정 CSS의 브라우저 재검증 및 모바일 스크린샷

마지막 브라우저 새로고침/시각 확인 요청은 자동 승인 검토 서비스의 용량 오류로 실행되지 않았습니다. 직전 기능 검증 후 변경한 내용은 짧은 화면에서의 높이 조정, 숫자 표시 소수점 정리, 완료 시간을 다시 클릭해도 고정하는 처리, 라이선스 번들링입니다. 최종 소스의 자동 테스트는 다시 실행해 통과했습니다.

## 행사 전에 반드시 실행할 샘플

- 기본 판형, 3글자
- 6글자, 가장 작은 크기
- 음각 + 전통 배치 + 타원
- 원형/육각 손잡이
- 가장 가는 글꼴, 획 보강 최소/권장 비교

사용 장비에서 슬라이스 후 레이어 미리보기와 실제 인영을 확인하여 행사 기본값을 확정하세요.
