## 알려진 한계

- A1 mini + 0.4mm + 외부 PLA + 텍스처 PEI의 확인된 조합을 대상으로 합니다. AMS, 다른 모델, 다른 노즐은 지원 범위가 아닙니다.
- 프린터 시작 직후 필라멘트 확인 등 현장 조작이 필요할 수 있습니다.
- 5분 내 실물 완성 보장이 아닙니다. 실제 시험은 현장 확인 대기 때문에 예상보다 길었습니다.
- 새 UI의 모든 이름/아이콘/음각에 대해 실물 출력하지 않았습니다.
- 실제 끼움 공차는 받침 제작품으로 확인해야 합니다.
- Pages에서 부스 PC에 연결하면 실제 슬라이싱·공유 대기표가 가능합니다. 부스 PC가 꺼져 있거나 기기 간 연결이 차단되면 연결할 수 없습니다. 운영자 출력 시작은 PC에서 확인합니다.

## 크롬북용 부스 모드 — 2026-10-20

자동 검사 20개 통과. 새 검사는 부스 링크·사설 주소 검증, CORS preflight, 참가자 키, 공유 접수, 외부 origin/Host 거부, 참가자에서 운영자 권한 사용 차단을 포함합니다. 프린터 설정이 없는 격리된 부스 서버의 LAN 주소로 두 요청을 동시에 보내 실제 Bambu Studio가 순서대로 계산하는 것을 확인했습니다. 각 11층·약 0.475g·준비 포함 약 8분 17초이며, 대기표 1/2를 발급한 후 시험 대기를 취소했습니다. 물리 출력 명령은 0회입니다.
