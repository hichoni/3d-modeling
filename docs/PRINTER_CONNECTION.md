# A1 mini 연결 — 출력 PC와 크롬북

**[다운로드부터 프린터 연결까지 웹에서 따라하기 →](https://hichoni.github.io/3d-modeling/setup.html)**. 화면의 ‘이 PC에서 출력’ 또는 ‘크롬북 여러 대와 함께’를 고르면 필요한 실행 파일과 단계가 나옵니다.

**8자리 코드는 프린터의 비밀번호입니다.** 공개 웹 주소나 Wi-Fi 비밀번호가 아닙니다. 현재 구성에서는 같은 Wi-Fi에 연결하고 코드만 공개 페이지에 입력해서 프린터로 전송할 수는 없습니다.

```text
웹 스튜디오 → 출력 PC의 연결 프로그램 → A1 mini
모델·슬라이싱     파일 전송·상태 통신       같은 Wi-Fi
```

연결 프로그램은 A1 mini가 사용하는 MQTT/FTPS 통신을 맡습니다. 슬라이싱은 브라우저에서 하므로 Bambu Studio는 기본 경로에 필요하지 않습니다. 일반 웹의 직접 TCP/UDP 통신과 별도 설치·권한을 가진 Isolated Web App은 다릅니다. [Chrome 공식 설명](https://developer.chrome.com/docs/iwa/direct-sockets)을 참고하세요. 현재 제품은 일반 웹+출력 PC 구성입니다.

## 출력 PC에서 처음 한 번

1. A1 mini와 출력 PC를 같은 Wi-Fi에 연결합니다. 프린터에서 LAN Only·Developer Mode를 켭니다. LAN Only도 Wi-Fi를 사용하며 유선 케이블이 필요하다는 뜻이 아닙니다. 클라우드·Handy 연결은 이 모드에서 제한됩니다.
2. 정책상 실행이 허용된 Windows PC에 공식 Node.js LTS를 설치하고 ZIP을 ‘모두 추출’합니다. 이 PC만 쓸 때는 `click-workshop/start-workshop.cmd`, 크롬북과 함께 쓸 때는 `configure-booth.cmd`를 더블클릭합니다. 처음에는 미니 대수만 입력하고, 함께 쓰기는 출력 PC 주소를 추가 확인합니다. IP·SN·8자리 코드는 다음 웹 화면에서 입력합니다. [5단계 웹 안내](https://hichoni.github.io/3d-modeling/setup.html)에 다운로드 버튼과 실행 화면 예시가 있습니다. Windows가 차단한 파일은 실행을 멈추고 학교 담당자에게 배포 승인을 요청합니다. 정식 Store 서명·출시는 아직 완료하지 않았습니다.
3. 웹 안내 마지막의 ‘프린터 연결 화면 열기’를 누릅니다. 직접 주소는 `http://127.0.0.1:5188/studio.html#connect=1`이며 접속 후 연결 창이 자동으로 열립니다. 이 PC 전용 실행의 검은 창은 닫지 않고, 함께 쓰기는 프로그램이 배경에서 실행됩니다. 이미 5186 화면을 사용하던 PC는 그 주소를 유지해 기존 매칭과 저장소를 이어갑니다. 별도 미리보기 프로그램은 출력의 필수 구성 요소가 아닙니다.
4. ‘프린터 연결’ → A1 mini 선택 → ‘프린터 처음 등록 · 연결 정보 수정’ → ‘같은 Wi-Fi에서 A1 mini 찾기’를 누릅니다. 본체와 같은 미니를 고르면 IP 주소·일련번호가 자동 입력됩니다. **본체의 8자리 코드만 입력**해 연결을 확인합니다. 여러 대일 때는 어느 미니인지 먼저 선택합니다. 코드를 검색하거나 가져오지는 않습니다.
   검색이 막히면 ‘검색이 안 될 때: IP·일련번호 직접 입력’을 펼칩니다. IP/코드는 LAN Only 화면, SN은 기기 정보에서 확인합니다. 현재 검색 결과를 등록할 프린터 칸은 기존 설정 목록에서 고릅니다. 프린터 칸을 추가하는 일은 운영자 최초 설정에서 합니다.
5. ‘연결 정보 저장하고 확인’이 성공하면 ‘이 프린터 사용하기’를 누릅니다. 등록된 코드는 출력 PC에만 저장하며 크롬북으로 전달하지 않습니다.

프로그램이 실행되지 않았으면 로컬 주소가 열리지 않습니다. 웹 페이지는 PC의 명령창이나 연결 프로그램을 자동 실행하지 않습니다. 프린터가 없어도 공개 웹에서 STL 편집·슬라이싱까지는 할 수 있습니다.

## 크롬북·다른 기기에서

1. 운영자가 출력 PC에서 **공유 연결을 설정**하고 연결 링크를 복사합니다. 같은 Wi-Fi만으로 다른 기기의 접근이 자동 허용되지는 않습니다.
2. 각 크롬북은 그 전체 링크를 엽니다. 공개 스튜디오에서 ‘프린터 연결’ → ‘크롬북·다른 기기’ → ‘출력 PC 연결하기’로 링크를 붙여넣어도 됩니다.
3. 비어 있는 A1 mini를 선택하고 ‘이 프린터 사용하기’를 누릅니다. 6대 크롬북은 각자 미니 한 대를 선택합니다. 이미 다른 기기가 사용하는 미니는 선택할 수 없습니다.
4. STL 업로드 → 레이어 계산 → 출력 준비 → 준비 항목 확인 → 출력 시작. 다음 작품을 자동으로 출력하지 않습니다.

8자리 프린터 코드는 크롬북에서 입력하지 않습니다. 운영자의 연결 링크에 들어 있는 인증 값과 프린터 코드는 서로 다르므로 링크를 공개 게시하지 않습니다. Chrome이 로컬 네트워크 연결을 물으면 실제 사용할 출력 PC인지 확인해 허용합니다. 학교 Wi-Fi가 기기 간 통신을 차단하면 학교 담당자의 네트워크 설정이 필요합니다.

## 화면이 알려주는 상태

| 화면 | 의미 / 다음 행동 |
| --- | --- |
| 출력 PC 연결 안내만 보임 | 연결 프로그램에 아직 접속하지 않은 상태. 이 PC는 프로그램 실행, 크롬북은 연결 링크가 필요 |
| 연결 프로그램 실행 중 / 출력 PC에 연결됨 | 프로그램과 연결 성공. 아래에서 프린터 선택 |
| 프린터 연결 확인 필요 | 프린터 전원·같은 Wi-Fi·LAN 모드·입력 정보를 확인 |
| 다른 기기에서 사용 중 | 현장 운영자가 기존 매칭을 해제하거나 다른 미니를 선택 |
| 실시간 연결 | 프린터가 최신 상태를 보내는 중. 출력 준비에서 베드·재료 확인 |

내부 API 버전·토큰·기술 용어를 사용자가 직접 설정하도록 요구하지 않습니다. 기존 링크 형식과 1:1 소유권·출력 준비 확인은 그대로 유지합니다.

자동 검색은 출력 PC에서 버튼을 눌렀을 때만 실행하는 읽기 전용 SSDP 검색입니다. IP 대역을 순회하지 않고 로컬 멀티캐스트로 A1 mini를 찾습니다. 검색 결과만으로 코드를 저장하거나 연결·출력을 시작하지 않습니다. 검색 UI·응답 필터·기기 선택은 격리된 가짜 UDP/프린터로 검증했습니다. 실제 학교 Wi-Fi의 검색 허용 여부는 현장 확인이 필요합니다.
