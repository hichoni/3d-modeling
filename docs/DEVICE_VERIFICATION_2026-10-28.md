# 실제 기기 업데이트·출력 확인 (2026-10-28)

이 문서는 **실제 기기에서 관찰하거나 사용자가 확인한 결과**만 통과로 기록한다. PC 자동 검사, 서명 검증, 모의 프린터 테스트를 실제 ChromeOS/Android 출력 성공으로 대체하지 않는다.

## 현재 상태

| 단계 | 크롬북 | Android 태블릿 |
| --- | --- | --- |
| 기기 준비 | 사용자 확인: 크롬북만 준비됨 | 준비되지 않음, 미실시 |
| 설치 방식/버전 | IWA임을 확인. 사용자 확인: 앱 창을 닫고 Update 재시도 후 **1.1.4 적용 완료**. 대문 개선판 1.1.5의 적용은 아직 미확인 | 미실시 |
| 기존 프린터 설정 유지 | 미확인 | 미실시 |
| 검색·인증·실시간 상태 | 미실시 | 미실시 |
| 실제 파일 전송·시작 | 미실시 | 미실시 |
| 출력 완료·실물 확인 | 미실시 | 미실시 |

시험 프린터와 베드/PLA 준비 상태는 아직 확인되지 않았다. 이번 실기 점검에서는 아직 프린터에 출력·가열·이동 명령을 보내지 않았다.

## 버전부터 구분

- 크롬북 전용 **IWA는 대문 개선판 1.1.5**. `chrome://iwa-dev`의 설치된 앱에서 Update 후 버전을 확인한다. 개발자 모드로 설치한 앱 자체의 자동 업데이트를 보장하지 않는다. 사용자의 1.1.4 적용 확인 후 화면 크기 문제를 수정한 후속 버전이다.
- **APK는 1.1.1(versionCode 3)**. 크롬북에서 APK를 쓰고 있다면 1.1.1이 이번 최신 버전이다.
- 온라인 웹 화면 갱신과 설치 앱/오프라인 화면 갱신은 다르다. 공개 설치 안내의 모호한 “업데이트는 자동이에요” 문구를 이 구분에 맞춰 수정했다.

## 한 대씩 확인할 순서

1. 앱 버전·설치 방식 확인 → 앱을 완전히 닫고 재실행 → 기존 프린터 등록 정보 유지 확인.
2. 같은 Wi-Fi에서 프린터 연결 화면 열기 → 시험할 A1 mini 선택 → 연결 상태, 본체와 같은 이름, 온도/진행 상태 수신 확인. 8자리 코드는 기기에 직접 입력하고 기록에 남기지 않는다.
3. 14mm 기본 키캡에서 간단한 그림 한 개로 시험 작품 생성 → 화면 반영·실행 취소·썸네일 확인.
4. 슬라이싱 → 층별 경로·예상 시간·선택 프린터 확인. 실제 출력 시간은 예열·보정·현장 상태에 따라 달라지므로 미리 고정하지 않는다.
5. 현장에서 베드 비움·PLA·대상 프린터 확인 후 기기에서 출력 시작 → 업로드 완료·프린터 수신·출력 진행률 확인. 운영자가 필라멘트 확인 등 본체 안내를 처리한다.
6. 프린터 완료 상태와 실물 출력물 확인 → 식힌 뒤 작품을 분리하고 기존 받침에 끼워 보기. 다음 기기 시험 전에 베드를 다시 비운다.

실패하면 어느 단계인지, 화면의 오류 문구, 앱/OS 버전, 발생 시각만 우선 기록한다. 액세스 코드·전체 일련번호·개인 정보가 있는 화면은 공개 MD에 넣지 않는다.
