# 개인정보 및 로컬 데이터 안내 · 초안

이 문서는 ‘상상을 클릭하다! 운영자 공방’의 현재 코드 동작을 설명하는 초안입니다. 앱 배포자는 실제 지원 연락처와 운영 방침을 확인한 뒤 Store 제출에 사용해야 합니다. 별도의 지원 연락처가 확정되기 전에는 공개 개인정보처리방침 확정본으로 안내하지 않습니다.

앱은 운영자 PC의 현재 사용자 데이터 폴더에 프린터 연결 설정, 운영자 PIN, 부스 접속 키, 기기 매칭 정보, 참가자 작품 이름, STL, 슬라이싱 결과와 작업 상태를 저장합니다. 프린터 접근 코드와 PIN은 정식 설치 패키지나 GitHub 저장소에 포함하지 않습니다. 참가자 브라우저에는 디자인, 부스 연결과 무작위 기기 키가 저장됩니다.

기본 코드에는 별도의 광고·분석 SDK나 개발자 클라우드로 보내는 참가자 업로드 기능이 없습니다. 부스 링크로 연결한 기기는 같은 네트워크의 운영자 PC와 통신하고, 운영자 PC는 설정한 프린터와 통신합니다. 공개 웹 화면과 배포 문서는 GitHub Pages에서 제공되며 해당 서비스의 네트워크 처리가 적용됩니다. 참가자가 STL 저장 또는 링크 복사를 선택하면 그 동작에 따라 파일·링크를 취급해야 합니다.

Bambu Studio는 별도 앱이며 이 공방이 대신하는 개인정보 정책 범위가 아닙니다. 운영자가 설치한 Bambu Studio와 Windows·Microsoft Store의 통신과 계정 처리는 각 제공자의 정책을 따릅니다.

참가자에게 다른 사람의 개인정보를 디자인에 넣지 않도록 안내하고, 행사 종료 후 필요한 작품만 비공개로 보관하세요. 브라우저 저장 정보는 해당 브라우저에서 지울 수 있습니다. PC의 작업 데이터는 모든 슬라이싱과 출력 상태를 확인하고 공방을 중지한 뒤 백업·삭제합니다. 자동 보관 기간이나 원격 삭제 기능은 제공하지 않습니다. 앱 제거 시 데이터 처리와 가상화 경로는 실제 서명 설치본에서 확인해야 합니다.

배포자·지원 연락처: 아직 미확정. 신원 확인용 신분증과 셀피는 Microsoft의 공식 개발자 등록 절차에서만 제출하며 앱이나 GitHub에서 수집하지 않습니다.
