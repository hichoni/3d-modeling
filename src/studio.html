    A1 mini 연결하기

    이 크롬북 앱이 같은 Wi-Fi의 A1 mini와 직접 연결해요.
    출력 PC·연결 프로그램은 필요 없어요.

    Click Studio 앱모델·슬라이싱·전송→A1 mini같은 Wi-Fi · LAN Only
    1. 프린터 화면: 설정 → LAN Only 켜기, 개발자 모드 켜기
    2. 아래 같은 Wi-Fi에서 A1 mini 찾기
    3. 프린터 화면의 액세스 코드 8자리 입력 → 연결

    8자리 코드는 프린터의 비밀번호예요.
    처음 한 번, 출력 PC의 연결 프로그램에 등록하면 됩니다.

    웹 스튜디오모델·슬라이싱→출력 PC연결 프로그램→A1 mini같은 Wi-Fi
    새 · 출력 PC 없이 크롬북만으로 Click Studio 앱을 설치하면 같은 Wi-Fi의 A1 mini로 바로 출력해요 ↗

    연결 프로그램은 여기서 받아요

    다운로드 → 압축 해제 → 실행 → 프린터 연결을 한 단계씩 안내합니다. Windows 출력 PC 한 대에만 준비하세요.

    연결 프로그램 받기 · 5단계 설정 →이미 방법을 알아요 · ZIP만 바로 받기 ↓이미 실행했어요 · 프린터 연결 화면 열기 ↗

    프로그램이 실행 중일 때 열립니다. Bambu Studio는 필요하지 않아요.

    학교 PC에서 실행을 차단했어요

    현재 ZIP은 정식 서명 전 개발용입니다. 차단되면 실행을 멈추고 학교 담당자에게 배포 승인을 요청하세요.

    차단됐을 때 따라 할 안내 →

    출력 PC에서 받은 연결 링크를 여세요

    여러 크롬북이 출력 PC 한 대를 함께 쓸 수 있어요. 각 크롬북에서 비어 있는 미니를 한 대씩 고르면 됩니다.

    이 칸에는 8자리 코드를 넣지 않아요. 프린터 코드는 출력 PC에만 입력합니다. 연결 링크를 바로 열었다면 자동으로 연결돼요.

    이 기기에서 사용할 프린터

    프린터 처음 등록 · 연결 정보 수정

    같은 Wi-Fi의 미니를 찾고, 본체 LAN Only 화면에 표시된 액세스 코드 8자리를 입력하세요.

    검색이 안 될 때: IP·일련번호 직접 입력

    IP 주소는 프린터의 LAN Only 화면, 일련번호(SN)는 기기 정보에서 확인해요.

    Wi-Fi 비밀번호가 아닙니다. 연결 정보는 출력 PC에만 저장해요.

    Wi-Fi 비밀번호가 아닙니다. 코드는 이 크롬북 앱 안에만 저장되고, 프린터 인증서(Bambu Lab)를 확인한 뒤에만 보냅니다.

    같은 Wi-Fi와 8자리 코드만으로 안 되나요?

    8자리 코드는 프린터 인증에 쓰는 비밀번호입니다. 일반 웹 페이지는 프린터의 파일 전송·상태 통신에 직접 접속할 수 없어 출력 PC의 연결 프로그램이 대신 전달합니다. 크롬북에는 Bambu Studio를 설치하지 않아도 됩니다.

    MakerWorld 모델 출력하기

    MakerWorld에서 마음에 드는 프로젝트를 골라 이 스튜디오로 가져오면, A1 mini에 맞게 다시 슬라이싱해서 바로 출력해요.

    1. MakerWorld 열기에서 모델을 고르고 원하는 프린트 프로필을 선택해요.
    2. Bambu Studio로 열기를 누르고 앱 목록에서 Click Studio를 골라요. 이 스튜디오로 바로 들어와요.
    3. 3MF 다운로드로 받은 파일을 아래 3MF 파일 열기로 골라요.
    4. 플레이트를 고르면 배치와 주요 설정(층 높이·채움·벽·서포트)을 가져와요. 색 칠하기·여러 재료는 PLA 한 가지로 출력해요.

      STL 스튜디오의 큰 모델·서포트·동적 종료 동작은 새 출력 경로입니다. 첫 출력에서 부착·간섭·품질을 직접 확인해주세요.

      파일에서 출력까지

      1. STL 불러오기바이너리·ASCII STL을 최대 6개 올립니다. 전체 6MB·120,000 triangles까지 지원합니다.
      2. 배치와 크기 확인드래그 이동, 회전·균일 배율, 자동 배치와 메쉬 진단을 사용합니다. 단위는 mm입니다.
      3. 실제 레이어 계산외벽·채움·서포트·브림을 설정하고 계산합니다. 변경한 설정은 재계산해야 합니다.
      4. 연결하고 출력 검토같은 Wi-Fi의 출력 PC에서 연결 프로그램을 실행하고 사용할 A1 mini를 선택합니다. 8자리 프린터 코드는 출력 PC에 한 번 등록합니다.

      면적 0인 면은 자동 정리합니다. 구멍 수리·트리 서포트·AMS·다른 프린터·다른 노즐·PETG는 지원하지 않습니다. 서포트와 얇은 벽은 레이어에서 확인해주세요.
