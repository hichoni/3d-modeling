프린터 연결 화면 열기 ↗

프로그램이 아직 실행되지 않았으면 이 주소는 열리지 않습니다. 웹에서는 PC 프로그램을 자동 실행하거나 실행 여부를 검사하지 않아요.

  1. A1 mini를 같은 Wi-Fi에 연결하고 LAN Only · Developer Mode를 켭니다. Wi-Fi 연결은 유지하며 Bambu 클라우드·Handy 연결은 제한됩니다.
  2. 웹 화면에서 등록할 미니를 선택하고 같은 Wi-Fi에서 A1 mini 찾기를 누릅니다.
  3. 본체와 같은 미니를 골라 본체의 8자리 액세스 코드를 입력합니다. Wi-Fi 비밀번호가 아니에요.
  4. 연결 정보 저장하고 확인 → 실시간 연결 확인 → 이 프린터 사용하기.

검색이 안 되면 ‘검색이 안 될 때: IP·일련번호 직접 입력’을 사용하세요. 연결 정보를 저장하는 것만으로 출력이 시작되지는 않습니다.

이제 크롬북에 연결 링크를 공유하세요

출력 PC의 체험 화면 ↗에서 ⚙ 운영자 화면 → 실행 때 표시된 PIN으로 잠금 해제 → 참가자 링크 복사. 각 크롬북이 이 링크를 열어 비어 있는 미니를 한 대씩 선택합니다. 링크는 현장 참가자에게만 공유하세요.

WHEN WINDOWS BLOCKS THE FILE

차단됐다면, 여기서 멈춰주세요

이 ZIP은 정식 서명 전 개발용입니다. Smart App Control이나 학교의 실행 정책이 차단한 경우 웹 안내만으로 해결되지 않아요.

  1. 차단 창의 파일명·발생 시각을 기록합니다. 프린터 코드·운영자 PIN은 공유하지 마세요.
  2. 학교 담당자에게 공개 소스와 아래 배포 검토 안내를 전달해 설치·실행 승인을 요청합니다.
  3. 승인된 출력 PC 또는 정식 서명 배포가 준비된 뒤 다시 진행합니다.
학교 담당자용 배포 검토 안내 ↗

보안 기능을 끄거나 차단된 파일을 다른 방법으로 실행하도록 안내하지 않습니다. 정식 Microsoft Store 출시는 아직 완료되지 않았습니다.

자주 막히는 부분

ZIP은 크롬북에서 받아도 되나요?

연결 프로그램은 출력용 Windows PC에서 실행해요. 크롬북은 출력 PC가 공유한 링크를 열어 웹 스튜디오를 씁니다. ZIP이나 Node.js를 설치하지 않습니다.

8자리 코드만 있으면 바로 출력되나요?

8자리 코드는 프린터 인증 비밀번호입니다. 출력 PC의 연결 프로그램이 켜져 있어야 웹에서 파일을 전달할 수 있어요. 연결 후에도 레이어 계산과 출력 전 확인을 거쳐야 합니다.

다음 날에는 무엇을 실행하나요?

이 PC만 사용하는 경우 start-workshop.cmd, 함께 쓰기 설정을 마쳤다면 start-booth.cmd를 실행하세요. 기존 프린터 등록 정보는 보관됩니다. 대수나 공유 설정을 바꾸려면 출력이 끝난 뒤 설정 파일을 실행합니다.

프린터 여섯 대도 가능한가요?

처음 실행에서 대수를 6으로 입력하고 각 미니를 웹에서 등록하세요. 크롬북도 각자 미니 한 대를 선택합니다. 출력 PC는 한 대를 함께 사용할 수 있습니다. 실제 학교 네트워크와 여러 대 동시 운영은 현장 확인이 필요합니다.
