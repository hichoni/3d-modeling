학교에서 관리하는 크롬북은 3단계 설정이 막혀 있을 수 있어요. 그럴 땐 학교 크롬북 안내를 보세요.

ALLOW INSTALL

앱 설치 허용 (처음 한 번)

웹 페이지에서는 Chrome 설정 주소를 바로 열 수 없어요. 아래 주소를 복사해 새 탭 주소창에 붙여넣으세요.

chrome://flags/#enable-isolated-web-app-dev-mode
  1. 노란색으로 표시된 Enable Isolated Web App Developer Mode를 Enabled로 바꿔요.
  2. 아래쪽 Restart(다시 시작)를 눌러요. 열린 탭은 다시 열려요.
4
INSTALL

앱 설치

Chrome 154부터 설치 화면이 chrome://iwa-dev로 옮겨졌어요. 아래 주소를 새 탭에 여세요.

chrome://iwa-dev

방법 A · 주소만 붙여넣기 (가장 쉬움)

  1. 오른쪽 위 + Install을 눌러요.
  2. Update Manifest 탭을 고르고 아래 주소를 붙여넣은 뒤 Fetch를 눌러요.
https://hichoni.github.io/3d-modeling/downloads/click-studio-update.json
  1. 최신 버전이 선택된 상태로 Install을 누르면 “Installation successful!”이 떠요.

방법 B · 받은 파일로 설치

  1. + Install → Signed Bundle 탭 → Install을 누르면 파일 선택 창이 열려요.
  2. 다운로드 폴더의 click-studio.swbn을 고르면 설치돼요.
파일 앱에서 .swbn을 더블클릭하지 마세요

그 방식은 “설치 번들을 확인하는 중…” 뒤에 “앱을 설치할 수 없음”이 나올 수 있어요. Google 허용 목록에 등록된 앱만 그렇게 설치되는 것으로 보이며, 이 앱은 아직 등록 전이에요. 위 방법 A·B를 쓰세요.

설치가 끝나면 런처(앱 목록)에 생긴 Click Studio를 열어요. 자주 쓰면 선반에 고정하세요. Chrome 버전이 낮아 chrome://iwa-dev가 없으면 chrome://web-app-internals 맨 위의 Isolated Web Apps 칸에서 같은 방법으로 설치해요.

웹 화면은 자동 반영, 설치 앱은 직접 업데이트해요

인터넷에 연결하면 앱 안의 웹 화면은 최신 내용을 불러와요. 하지만 설치된 앱의 버전과 오프라인 화면은 저절로 바뀌지 않아요.

크롬북 전용 앱(IWA)은 chrome://iwa-dev에서 기존 Click Studio 옆 Update를 누르고, 위 ‘앱 파일 받기’에 표시된 최신 버전인지 확인하세요. 앱을 삭제할 필요는 없어요.

APK로 설치한 앱은 크롬북에서 실행하더라도 아래 태블릿 앱 버전과 비교하세요. 새 APK를 받아 기존 앱 위에 업데이트 설치하면 돼요. 두 앱의 버전 번호는 서로 달라요.

5
PRINTER

프린터 준비 (처음 한 번)

  1. A1 mini와 크롬북을 같은 Wi-Fi에 연결해요.
  2. 프린터 화면 설정 → LAN Only를 켜요. Wi-Fi는 그대로 쓰고, 클라우드 연결만 꺼져요.
  3. 같은 화면에서 개발자 모드(Developer Mode)를 켜요. 꺼져 있으면 출력 명령을 받지 않아요.
  4. 화면에 보이는 액세스 코드 8자리를 확인해요. Wi-Fi 비밀번호가 아니에요.
6
CONNECT & PRINT

연결하고 출력하기

  1. Click Studio 앱 → STL 스튜디오(또는 키캡 만들기)를 열어요.
  2. 프린터 연결 → 같은 Wi-Fi에서 A1 mini 찾기를 눌러요. 최대 20초 걸려요.
  3. 본체와 같은 미니를 고르고 8자리 코드를 입력 → 연결 정보 저장하고 확인.
  4. 연결되면 그 미니가 이 크롬북의 프린터로 정해져요. STL 불러오기 → 레이어 계산 → 출력 준비 → 출력 시작.
출력 단계·층·남은 시간일시 정지 · 계속속도 4단계조명 켜기·끄기프린터 화면 미리보기 그림오류 코드 안내

여러 크롬북과 여러 미니를 쓸 때는 크롬북마다 미니 한 대씩 등록하면 돼요. 다른 기기가 출력 중인 미니는 끝날 때까지 시작할 수 없어요.

ANDROID TABLET · BETA

안드로이드 태블릿 앱

안드로이드 태블릿은 Click Studio 태블릿 앱(APK)으로 같은 Wi-Fi의 A1 mini에 바로 출력해요. 앱은 이 사이트의 최신 화면을 그대로 쓰기 때문에 화면이 바뀌어도 다시 설치할 필요가 없어요.

APK
click-studio.apk

Click Studio 태블릿 앱 · Android 10 이상

태블릿 앱 받기 ↓
  1. 태블릿의 Chrome에서 이 페이지를 열고 태블릿 앱 받기를 눌러요.
  2. 다운로드가 끝나면 알림이나 파일 → 다운로드에서 click-studio-v(버전).apk를 열어요. 출처를 알 수 없는 앱 설치를 물으면 이 앱(Chrome 또는 파일)에 허용한 뒤 설치를 눌러요.
  3. Click Studio 앱을 열고 프린터 연결 → 같은 Wi-Fi에서 A1 mini 찾기를 누른 뒤, 프린터 화면의 액세스 코드 8자리를 입력해요.

앱이 연결하는 곳은 같은 Wi-Fi의 사설 IP 프린터뿐이에요(MQTT 8883 · FTPS 990 · 검색 UDP 2021). 앱에서 저장한 STL·작품 파일은 다운로드/ClickStudio 폴더에 들어가요. 학교에서 관리하는 태블릿은 APK 설치가 막혀 있을 수 있어요. 그럴 땐 관리자에게 이 앱 허용을 요청하세요.

문제 해결

chrome://web-app-internals에 글자만 잔뜩 보이고 누를 게 없어요

정상이에요. Chrome 154부터 그 페이지는 기록 보기용이고, 설치 화면은 chrome://iwa-dev로 옮겨졌어요. 4단계를 따라 하세요.

chrome://iwa-dev가 열리지 않아요

3단계 설정이 적용되지 않은 상태예요. flags에서 Enabled로 바꾼 뒤 Restart를 눌렀는지 확인하세요. chrome://version에서 Ctrl + F로 IsolatedWebAppDevMode가 보이면 적용된 거예요.

학교·기관 계정이면 개발자 도구 정책이 막고 있을 수 있어요. chrome://policy에서 DeveloperToolsAvailability 값이 2면 막힌 상태예요. 학교 Google 관리자에게 선생님 계정의 개발자 도구 허용을 요청하거나, 개인 크롬북 또는 기존 출력 PC 방식을 쓰세요.

학교 크롬북이라 3단계 설정이 안 보여요

학교 계정 크롬북은 보통 Chrome 설정 변경이 막혀 있어요. 학교 Google 관리자에게 관리 콘솔에서 이 앱을 Isolated Web App으로 설치해 달라고 요청하세요.

웹 번들 ID
https://hichoni.github.io/3d-modeling/downloads/click-studio-update.json

관리 정책 설치에는 Google의 IWA 허용 목록 등록이 필요해요(Chrome 143부터). 아직 등록 신청 전이라, 그동안은 개인 크롬북이나 출력 PC 방식을 쓰세요.

프린터를 찾지 못해요

전원, 같은 Wi-Fi, LAN Only를 확인하세요. 학생용·손님용 Wi-Fi는 기기끼리 통신을 막는 경우가 많아요. 그래도 안 되면 검색이 안 될 때: IP·일련번호 직접 입력을 펼쳐 프린터 화면의 IP를 넣고 이 IP의 일련번호 자동 확인을 누르세요.

액세스 코드 인증이 거절돼요

코드는 LAN Only를 껐다 켜면 바뀌어요. 프린터 화면에 지금 보이는 8자리를 다시 입력하세요. 대소문자도 그대로 입력해요.

“개발자 모드가 꺼져 있어요” 경고가 나와요

프린터 설정 → LAN Only 화면에서 개발자 모드를 켜세요. 최신 펌웨어는 개발자 모드가 꺼져 있으면 서명 없는 출력 명령을 거절해요.

“인증서로 확인되지 않는 장치” / “일련번호가 다릅니다”

입력한 IP가 다른 기기이거나 일련번호가 다를 때 나와요. 앱은 Bambu Lab 인증서와 일련번호가 맞는 프린터에만 코드를 보내요. 프린터 화면의 IP와 기기 정보의 SN을 다시 확인하세요.

코드는 어디에 저장되나요?

이 크롬북의 Click Studio 앱 전용 저장소에만 저장되고 어떤 서버로도 보내지 않아요. 등록을 지우려면 프린터 연결 창의 이 크롬북에서 이 프린터 등록 삭제를 누르세요.

앱 없이 웹에서는 안 되나요?

일반 웹 페이지는 프린터의 파일 전송·상태 통신을 직접 열 수 없어요. 설치한 앱만 Chrome의 Direct Sockets 기능으로 프린터와 직접 통신해요. 웹에서는 모델링·슬라이싱까지 되고, 출력은 앱이나 출력 PC가 필요해요.
