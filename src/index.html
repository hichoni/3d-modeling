    웹에서 실제 슬라이싱할 수 있어요. 현장 공방을 연결하면 매칭한 미니의 출력도 관리할 수 있어요.

    Windows 연결 프로그램 받기 · 설정 따라하기 →
    실행 후 로컬 공방 열기 ↗
    공용 PC · Node.js가 필요합니다. Bambu Studio는 대체 계산용 선택 사항입니다.

    크롬북·참가자 접속 링크

    모든 크롬북에 이 부스 링크를 공유하세요. 각 기기에서 비어 있는 미니를 골라 현장 1:1 매칭해요.

    직접 접속 링크

    로컬 네트워크 허용 창을 사용할 수 없을 때 운영자 안내에 따라 여세요.

    크롬북에서 함께 체험하려면 출력 PC에서 configure-booth.cmd로 부스 모드를 한 번 설정하세요.

    출력 전 확인

    다음 작품은 자동으로 출력하지 않습니다. 본체의 필라멘트 확인 요청은 현장에서 처리하세요.

    우리 부스에 연결해요

    운영자가 공유한 부스 링크로 접속하면 크롬북에서도 바로 출력할 수 있어요.

    A1 mini 직접 연결

    이 출력 PC에 저장이 크롬북 앱에 저장 · 출력 PC 필요 없음
    1. 프린터 화면: 설정 → LAN Only와 개발자 모드를 켜요.
    2. 같은 Wi-Fi에서 찾기로 내 미니를 골라요.
    3. 프린터 화면의 액세스 코드 8자리를 입력해요.

    프린터 주소 · 일련번호 확인

    프린터 본체의 LAN 액세스 코드 8자리를 입력하세요. 코드는 이 PC에만 저장돼요.프린터 본체의 LAN 액세스 코드 8자리예요. 이 크롬북 앱 안에만 저장되고 Bambu Lab 인증서를 확인한 프린터에만 보내요.

    다른 부스의 공유 링크로 연결

    부스와 같은 Wi-Fi에 연결해주세요. Chrome이 로컬 네트워크 연결을 묻는다면 허용해주세요.

    운영자 처음 설정

    연결 프로그램 다운로드부터 프린터 연결까지 · 5단계 안내 →

    공방 PC 한 대에 여러 미니를 등록해요. 크롬북은 링크를 열어 현장에서 미니를 매칭하므로 설치가 필요 없어요.

    ↓ 운영자 설정 파일 받기 (ZIP)
    1. 다운로드한 ZIP을 폴더에 압축 해제해요.
    2. 실행이 허용된 운영자 PC에서 폴더 안의 configure-booth.cmd를 열어요.
    3. 미니 대수와 출력 PC 주소를 확인하고, 웹에서 프린터를 찾아 8자리 코드를 입력해요. ⚙ 화면에서 부스 링크를 공유해요.

    출력 PC에는 Node.js 20 이상이 필요해요. 웹 엔진은 Bambu Studio 없이 계산해요. ZIP 안에서 바로 실행하지 말고 먼저 압축을 풀어주세요.
