# 새김 — 5분 도장 공방

이름 도장 HTML 초안을 **부스에서 약 5분 동안 자기만의 3D 모델을 만들고 현장 출력 담당자에게 전달하는 체험**으로 발전시킨 프로젝트입니다.

**실행:** [index.html](./index.html)을 다운로드한 뒤 Chrome 또는 Edge에서 열면 됩니다. 설치·로그인·서버·인터넷 연결이 필요하지 않습니다. GitHub의 코드 화면 대신 파일을 내려받아 실행하세요. 저장소 전체는 **Code → Download ZIP**으로 받을 수 있습니다.

> 5분은 디자인 체험 시간입니다. 실물 출력 시간과 수령 시점은 프린터·소재·슬라이서 설정·대기열에 따라 운영자가 안내합니다.

## 체험 흐름

| 단계 | 참가자가 하는 일 | 권장 시간 |
| --- | --- | --- |
| 1. 취향 고르기 | 4가지 스타일 중 출발점 선택 | 0:00–1:00 |
| 2. 나를 새기기 | 이름·별명, 글꼴, 배치, 볼록/오목 선택 | 1:00–2:30 |
| 3. 입체로 다듬기 | 모양·크기·새김 높이·손잡이를 직접 조절 | 2:30–4:00 |
| 4. 작품 완성 | 작품 카드 확인, 출력용 묶음 저장, 제작 번호 접수 | 4:00–5:00 |

## 구현한 기능

- 4단계 안내, 부드러운 5분 타이머, 확인 후 다음 참가자 초기화
- 4개 디자인 프리셋, 한글/영문/숫자 최대 6자, 오프라인 한글 글꼴 4종
- 모양 5종, 배치 4종, 양각/음각, 판형/원형 손잡이/육각 손잡이
- 도장 크기·세로 길이·새김 높이·손잡이 높이·테두리·획 보강·바닥 두께 조절
- 실시간 3D 회전·확대, 선택형 자동 회전, 시점 복원, 종이에 찍힌 모양
- 도장용 좌우 반전 자동 적용, 실제 치수 표시, 작은 글자/가는 획/손잡이 안내
- 6가지 미리보기 색상. 실제 출력 색상은 필라멘트로 결정되며 STL에는 포함되지 않음
- STL 단독, PNG 작품 카드, 또는 STL+PNG+JSON+안내문을 ZIP으로 다운로드
- 제작 번호 자동 생성. 별도 접수 서버나 자동 프린터 전송은 없음
- 이름/작품의 서버 전송·브라우저 영구 저장 없음. 다운로드한 파일은 기기에 남음
- 모든 스크립트·글꼴·라이선스가 포함된 단일 오프라인 HTML 약 12.3 MB

## 현장 운영

자세한 절차는 [BOOTH_GUIDE.md](./docs/BOOTH_GUIDE.md)를 참고하세요. 기본값은 **24 × 24 mm, 바닥 3 mm, 새김 1.2 mm, 손잡이 없는 판형**입니다. 빠른 진행을 위해 기본값을 사용하고, 손잡이는 대기 상황에 따라 선택하도록 안내하세요.

ZIP 저장은 **출력 접수 완료나 프린터 전송을 뜻하지 않습니다.** 운영자가 실제 다운로드를 확인하고 STL을 슬라이서에 넣어 접수해야 합니다. STL은 겹치는 닫힌 메쉬로 구성되어 있으므로 슬라이서의 결합/병합 처리와 레이어 미리보기 확인이 필요합니다.

## 개발

Node.js 18 이상만 있으면 됩니다. `npm install`은 필요하지 않습니다.

```sh
node scripts/build.cjs
node scripts/serve.cjs
node --test tests/engine.test.cjs
```

로컬 미리보기: `http://127.0.0.1:5186`

`npm`이 설치된 환경에서는 `npm run build`, `npm start`, `npm test`도 같습니다. `src/`를 수정한 뒤 빌드해야 루트 `index.html`에 반영됩니다. 결과 HTML은 저장소에 함께 관리합니다.

```text
index.html                 배포/현장 실행용 단일 HTML
src/index.html             화면 구조
src/style.css              반응형 스타일
src/state.js               기본값, 프리셋, 입력 규칙
src/engine.js              글자 렌더링, 윤곽, 3D 메쉬, STL, ZIP
src/app.js                 참가자 흐름, 3D 뷰어, 다운로드
fonts/                     원본 한글 글꼴과 OFL 라이선스
vendor/                    Three.js r128, OrbitControls, MIT 라이선스
scripts/                   오프라인 빌드, 로컬 서버, STL 검사
tests/                     기하/파일 형식/오프라인 패키징 테스트
docs/BOOTH_GUIDE.md         운영자 진행 대본과 현장 출력 절차
docs/DEVELOPMENT.md         구조, 변경 포인트, 남은 개선 과제
docs/VALIDATION.md          수행한 검증과 검증하지 않은 범위
docs/THIRD_PARTY.md         의존성 출처와 라이선스
```

## 검증 범위

기하/파일 형식/오프라인 빌드 자동 테스트 9개, 브라우저의 이름 입력→설정→완성→ZIP 다운로드, 초기화/빈 입력 차단을 검증했습니다. 실제 다운로드한 STL은 삼각형 수와 치수, 유한 좌표, 열린 경계 여부를 검사했습니다. 자세한 기록은 [VALIDATION.md](./docs/VALIDATION.md)에 있습니다.

**실물 출력 및 슬라이서별 적합성은 아직 검증하지 않았습니다.** 운영 전에 사용할 장비로 샘플 출력이 필요합니다.

## 출처

사용자가 제공한 `stamp-maker-2.html`의 캔버스 글자 윤곽 추출·메쉬 생성·STL/ZIP 코드를 기반으로 화면과 체험 흐름을 다시 구성했습니다. 제공받은 원본 파일 자체는 저장소에 업로드하지 않았습니다. 포함된 공개 글꼴 및 Three.js의 라이선스는 [THIRD_PARTY.md](./docs/THIRD_PARTY.md)를 참고하세요.
